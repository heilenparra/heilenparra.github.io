Pruebas de API REST

Descripción

Diseño y ejecución de escenarios de API Testing para validar endpoints REST, métodos HTTP, parámetros y cuerpos de solicitud en formato JSON.

En el contexto de Urban.Scooter, validé la calidad de una aplicación web y móvil para el alquiler de scooters eléctricos. Analicé los requisitos funcionales, diseñé pruebas aplicando técnicas como partición de equivalencias y valores límite, y validé la integración de datos con Postman y DevTools, asegurando precisión en los flujos backend y front-end. Este trabajo me permitió optimizar pruebas funcionales y de UI y documentar hallazgos en JIRA.

Qué hice

  • Validación de endpoints REST.
  • Revisión de métodos HTTP, parámetros, Request Body y JSON.
  • Cobertura de escenarios positivos y negativos.
  • Validación de valores inválidos, códigos de respuesta y mensajes de error.
  • Verificación de campos obligatorios y reglas de negocio.

Resultados destacados

  • Diseñé y ejecuté 54 casos de prueba para validaciones de API.
  • Probé 4 endpoints utilizando Postman.
  • Reporté 22 errores documentados en JIRA y priorizados según severidad.
